# 📌 Overview

Mobility4You е конзолно Java приложение за управление на каталог от автомобили.
Поддържа различни типове превозни средства и позволява четене, добавяне, сортиране и запис във файл.

⚙️ Functionalities
📖 Четене на данни от CSV файл (mobility.csv)
➕ Добавяне на нови автомобили:
Electric Car
Gas Car
Hybrid Car
📋 Показване на целия каталог
🔍 Филтриране по:
тип автомобил
име на автомобил
🔄 Сортиране чрез Comparator (по тип)
💾 Запис обратно във файла

# 🧱 Project Structure
Проектът е организиран на нива според отговорностите на класовете.
В папката `models` се намират основните домейн класове. Там е интерфейсът `Vehicle`, както и конкретните имплементации (Electric, Gas, Hybrid), създавани чрез builder-и. Вътре има и под-пакет type, който съдържа VehicleType enum-а, а той определя типа на превозните средства като цяло.

Пакетът `ui` съдържа всички команди. Тук е приложен `Command pattern` – всяко действие (добавяне, показване, запис) е отделен клас. Класовете AddNew* се грижат за създаване на нови автомобили, Show* за визуализация, а `CatalogueWriter` записва данните обратно във файла.
В `unitility (utility)` има помощни компоненти. Под-пакетът context държи състоянието на приложението (списъци с прочетени и нови автомобили), а parser се грижи за преобразуването на текстови редове от CSV файла в обекти.
Пакетът constants съдържа всички съобщения за грешки, за да не са хардкоднати из целия код.
В `resources` се намира файлът `mobility.csv`, който играе ролята на база данни – от него се чете и в него се записва.
Накрая, `Main.java` е входната точка на приложението – оттам започва изпълнението и се управлява целият flow.

# 🧠 Key Concepts Used
OOP (Object-Oriented Programming)
Builder Pattern → създаване на различни типове автомобили
Command Pattern → всяко действие е отделен клас
Comparator → сортиране по тип автомобил
Context Pattern (simple state holder) → управление на данни между операции
File I/O (NIO + Streams) → четене/запис на CSV

# 📄 Data Format (CSV)

HYBRID_CAR Toyota, Prius, 1.5L, 50KW, 12000Ah, 24000 euro`

# ▶️ How to Run
Отвори проекта в IntelliJ IDEA
Увери се, че src/main/resources е маркиран като Resources Root
Стартирай:
`Main.java`

# ⚠️ Important Notes
Приложението чете и пише директно във файла:
`src/main/resources/mobility.csv`
При реална среда това не е добра практика (resources са read-only при JAR)
Форматирането на числа използва Locale.US за да се избегнат проблеми с , и .
